# BtSCTF-2026-writeups
Writeups for challenges from the CTF competition "Break the Syntax CTF 2026", organised by [KN White Hats](https://whitehats.pwr.edu.pl/) research group from Wrocław University of Science and Technology.

Each folder contains the challenge files, my solution scripts, and a `README.md` with a detailed walkthrough.

*   **[Reverse Engineering](./reverse)** - Decompiling binaries, analyzing logic and bypassing protections.
*   **[Web](./web)** - Exploiting web vulnerabilities.

## Tools used
* **RE:** Ghidra, gdb, Python
* **Web:** Burpsuite, feroxbuster, Web Browser
